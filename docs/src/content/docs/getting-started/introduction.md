Catwalk is a preview image generation tool custom-built for Catppuccin,
allowing developers to easily generate beautiful previews for their ports.

Simply running `catwalk <latte_file> <frappe_file> <macchiato_file> <mocha_file>` can generate a beautiful `preview.webp` combining all four flavors into one image.

To install Catwalk and start generating previews, see the
[Installation](/getting-started/installation) and [Quick
Start](/getting-started/quick-start) sections.
